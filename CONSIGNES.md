# Consignes

## Déroulement

Vous disposez de **2 heures**. Le fichier `BRIEF.md` contient le message de notre cliente, avec
trois demandes.

Il n'est pas attendu que vous les terminiez toutes les trois. Nous nous intéressons autant à
votre façon de travailler qu'au code produit.

## Ce qui est autorisé

Internet, la documentation et les assistants IA sont autorisés, sans restriction. Indiquez
simplement dans votre rendu comment vous vous en êtes servi.

Une personne de chez nous joue le rôle de la cliente et reste joignable sur Teams pendant toute
la durée de l'épreuve. N'hésitez pas à lui poser vos questions.

## Pendant l'épreuve

Commitez régulièrement, au fil de votre avancement.

## Les 10 dernières minutes

Complétez le fichier `RENDU.md` : ce qui est fait, ce qui ne l'est pas, les choix que vous avez
faits, les questions restées ouvertes et votre usage de l'IA.

## Pour terminer

Une démo orale de 5 minutes, où vous nous montrez ce que vous avez fait.
